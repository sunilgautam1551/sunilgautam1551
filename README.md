## 👨‍💻 About Me

I'm a frontend engineer with ~6 years of experience, focused on the architecture and performance of **large React, Next.js, and TypeScript applications**. ## 🎯 Where I Create Leverage

### ⚡ Web Performance
- Treat performance as a **budget, not a cleanup task**: bundle size, LCP, INP, and CLS are tracked and defended
- Reduced **JavaScript bundle size by ~30%** by analyzing bundle composition, redrawing client/server loading boundaries, route-level code splitting, and removing heavy dependencies from critical paths
- Improved **initial load time by ~35%** by optimizing the critical rendering path, deferring non-critical UI, tuning image/font delivery, and smarter prefetching and caching
- Cut **API calls and re-renders by 60–80%** with request caching, deduplication, memoization, and render-boundary design

### 🏛️ Frontend Architecture
- Component-driven architecture, shared **design systems**, and reusable libraries that keep large codebases consistent
- **Micro-frontends** and modular boundaries so teams can own, ship, and scale features independently
- Rendering strategy choices (**SSR, SSG, CSR, streaming**) matched to each route's needs
- Hybrid routing strategies that let legacy and modern UIs run side by side during migrations

### 📡 Real-Time & Data-Intensive UIs
- Real-time interfaces over **WebSockets and SSE** with batching, throttling, and backpressure-aware updates
- Experience rendering **10k+ live map markers** smoothly using clustering, viewport culling, and batched updates
- High-density grids and dashboards kept responsive with **virtualization/windowing** and main-thread optimization

### 🛡️ Platform Quality
- Enterprise auth: **Keycloak, OAuth 2.0 / OIDC, RBAC/ABAC**
- Accessibility built in from the start (**WCAG 2.2**): keyboard navigation, focus management, semantic HTML
- Testing strategy and standards with **Jest, React Testing Library, and Playwright**

## 🚀 Featured Project

### 🎨 CoBoard: Real-Time Multiplayer Whiteboard

[![Live Demo](https://img.shields.io/badge/Live_Demo-canvasroom.vercel.app-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://canvasroom.vercel.app/)

A multiplayer whiteboard with an infinite canvas. Create a board, share the link, and draw together live. No signup needed.

- ✏️ Whiteboard engine built from scratch: freehand drawing, shapes, arrow binding, text labels, selection and transform, and infinite pan/zoom
- 🔄 **Operation-based sync protocol** on Supabase Realtime, with last-write-wins conflict resolution and broadcasting that stays within the message budget (throttled cursor and drag updates, capped payloads)
- 💾 Saves and recovers state with debounced Postgres snapshots, hydration replay, and auto-reconnect with exponential backoff
- 📱 Accessible and works on mobile. Deployed on **Vercel at zero infrastructure cost**

`React` `TypeScript` `react-konva` `Supabase Realtime` `Postgres` `Vercel`

## 💭 Engineering Philosophy

> **Build for maintainability first, optimize where it matters, and keep complexity where it belongs.**

- **Measure before optimizing.** Profiling, bundle analysis, and Core Web Vitals drive decisions, not guesses.
- **Architecture is a team tool.** Good boundaries let many engineers move fast without stepping on each other.
- **Performance is a feature.** Every kilobyte and every render has a cost your users pay.
- **Migrate incrementally.** Big-bang rewrites are risky; strangler patterns and hybrid routing ship value sooner.
- **Make the right way the easy way.** Design systems, lint rules, and templates scale standards better than documents.
